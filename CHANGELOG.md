# Changelog

## 0.1.0 (2026-11-22, local)
- Core: JSON, HTTP transport interface, log redaction, environment guard; Keycloak PKCE sign-in with refresh,
  host-page token; games (scores), analytics (accepted events only), Insights, Chain (read-only), Assets (create +
  presigned upload), Live (web-bridge relay), Models (glTF text: OBJ import, stats, validation, decode). 44 tests.
- Unity: UnityWebRequest transport, WebGL host bridge, TupicGame, text-model meshes, sample "Tupic Stars", Tupic
  menu (sample scene, OBJ import, WebGL build for Tupic), batch entry. Built in Unity 6000.3.10f1 batch mode.
